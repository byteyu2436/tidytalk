Tidytalk 安装说明（试用版）

系统要求：macOS 26 或更高版本，Apple 芯片（M 系列）的 Mac。

1. 把 Tidytalk 拖到旁边的"应用程序"文件夹。

2. 第一次打开：
   这个试用版没有经过苹果公证，第一次打开时系统会提示无法验证开发者。
   请打开"系统设置 › 隐私与安全性"，滚动到页面底部，点"仍要打开"，再确认一次。

   也可以在"终端"里执行下面这行，之后就能直接双击打开：
   xattr -dr com.apple.quarantine /Applications/Tidytalk.app

3. 按照首次启动的引导完成：
   - 授权麦克风（用于录音，音频只在本机识别）
   - 授权辅助功能（用于监听快捷键和粘贴文字）
   - 配置 AI：填写接口地址和你自己的 API Key（可以跳过，跳过后直接粘贴识别原文）
   - 下载语音识别模型（约 240 MB，只需下载一次）

4. 使用：在任意输入框里放好光标，按住 Option + Command 说话（可以在设置里换成其他键），松开后文字会自动粘贴进去。

配置保存在你自己电脑的 ~/.tidytalk.json 中。

卸载：
把 Tidytalk 拖进废纸篓只会删除应用本身，语音模型（约 230 MB）和配置会留在电脑上。完整卸载：

1. 如果开启了开机自动启动，先在设置里关掉，再在菜单栏图标里选"退出 Tidytalk"。
2. 把"应用程序"文件夹里的 Tidytalk 拖进废纸篓。
3. 在"终端"里执行下面几行：
   rm -rf ~/Library/Application\ Support/Tidytalk
   rm -f ~/.tidytalk.json
   defaults delete app.tidytalk.Tidytalk
   tccutil reset All app.tidytalk.Tidytalk

这几行依次删除：语音识别模型；配置文件（含 API Key 和词库，想重装后保留设置可以不删）；系统保存的偏好；麦克风和辅助功能授权。
授权也可以在"系统设置 › 隐私与安全性"的"麦克风"和"辅助功能"里选中 Tidytalk，点"−"手动移除。
