声音和文字都不离开你的 Mac

Tidytalk 始终在你的 Mac 上识别语音。再接上本机大模型，整理文字也在本机完成。

什么会离开你的 Mac

设置声音文字
云端 AI 服务（例如 DeepSeek、OpenAI）留在本机发送给你选的 AI 服务
Ollama 或 LM Studio 本机模型留在本机留在本机
关闭"整理文字"留在本机留在本机（识别原文）

语音识别用的是 SenseVoice 模型，第一次下载约 240 MB 后就在本机运行。说话记录默认在这台 Mac 上保存 30 天，可以在“设置 › 隐私与数据”里关掉。设置保存在 ~/.tidytalk.json，只有你自己能读写；API Key 存在 macOS 钥匙串里。

除了你配置的 AI 服务，Tidytalk 只在下载模型、检查更新（启动时每天最多一次，可以在"设置 › 通用"里关闭）和转写链接时联网。每一项写在隐私说明里。

接入 Ollama

  1. 安装 Ollama。
  2. 在终端下载一个模型，例如： 
    ollama pull qwen2.5:7b
  3. 在 Tidytalk 里打开"设置 › AI 服务"，在顶部选 Ollama，确认模型名和刚才下载的一致，点 ✓ 按钮保存。
  4. 点旁边紫色的网络图标测试连接，显示"连接成功"就可以用了。

接入 LM Studio

  1. 安装 LM Studio，下载并加载一个模型。
  2. 打开 LM Studio 的本地服务。
  3. 在 Tidytalk 的"设置 › AI 服务"顶部选 LM Studio，填上已加载的模型名，保存后点紫色的网络图标测试连接。

本机模型不需要 API Key，超时时间也从 12 秒放宽到 60 秒。

怎么选模型

  • 整理文字不难，但模型要听话：只整理你说的话，而不是去回答它。小模型在这点和遵守自定义规则上不太稳定。
  • 建议从 7B 左右或更大的模型开始。qwen2.5:7b 下载约 5 GB，中英文都处理得不错。
  • 本机模型太慢或返回异常时，Tidytalk 会粘贴识别原文，你说的话不会丢。

完全不用 AI

在"设置 › 说话输入"里关闭"整理文字"，Tidytalk 就是一个快速、完全离线的语音转文字工具。固定替换、快捷短语和中英文排版规范仍然有效，因为它们本来就在本机处理，不需要 AI。

可以自己核实

Tidytalk 以 MIT 许可证开源。它什么时候发送什么内容，都可以在 GitHub 上看源码确认，也可以自己从源码编译。
