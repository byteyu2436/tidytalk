Tidytalk

Tidytalk 是段落式的：按住快捷键，说完一整段，松开。语音用 SenseVoice 模型在你的 Mac 上识别，再由你选的 AI 服务去掉口头禅和口误、补好标点，最后粘贴到光标处。

  • 文字发到哪里由你决定。可以用 DeepSeek、OpenAI 等任何 OpenAI 兼容接口，配你自己的 API Key；也可以接 Ollama、LM Studio 本机模型，什么都不离开电脑。声音从不上传。
  • 免费开源。没有字数限制，也没有订阅。用云端 AI 时，按用量直接向服务商付费。
  • 擅长中英文混说。中文里夹着的英文术语原样保留，自动处理中英文之间的空格，还能在整理时顺便翻译。
  • 需要知道的限制：只支持 Mac，且需要 macOS 26 及以上、Apple 芯片。能识别的语言有五种：中文、英文、日文、韩文和粤语。安装包还没有公证，第一次打开要在系统设置里允许一次。用 AI 整理需要自己配置 API Key 或本机模型。

Wispr Flow

Wispr Flow 是一款打磨得很好的商业软件，能在任何应用里把语音变成通顺的文字，还会学习你常用的人名和术语。它支持 Mac、Windows、iOS 和 Android，如果你需要在多台设备上用语音输入，它最省心。

  • 免费版电脑端每周 2,000 词、手机端每周 1,000 词。Pro 不限字数，每月 15 美元，按年付每月 12 美元。
  • 根据 Wispr 自己的帮助文档，转写始终在云端完成；隐私设置控制的是是否用于训练和是否保存，而不是在哪里处理，所以没有离线模式。

Superwhisper

Superwhisper 是一款功能很多的商业软件，可以配置不同的 AI 模式来改写你说的话，从随手消息到结构化笔记都行。它支持 Mac、Windows、iOS 和 Android。

  • 可以用本机模型离线转写，官网说明本机模型在 Apple 芯片的 Mac 上效果最好，也可以选云端模型。
  • 有免费版，付费 Pro 有按月、按年和买断三种方式，具体价格请看官网。

macOS 听写

听写是 macOS 自带的，免费，不用任何设置。在 Apple 芯片的 Mac 上，支持的语言会在本机处理。它边说边把话逐字打出来，适合快速输入，但会保留口头禅，不会整理或调整你说的内容。静默 30 秒后会自动停止。

该选哪个？

  • 选 Tidytalk：你想要免费开源的工具，在意文字发到哪里，或者经常中英文混着说。
  • 选 Wispr Flow：你需要在 Windows 和手机上也用同样的语音输入，不介意云端处理和订阅。
  • 选 Superwhisper：你想要大量可自定义的 AI 模式和多平台离线模型，愿意为 Pro 付费。
  • 继续用 macOS 听写：你只需要逐字快速输入，不需要去掉口头禅。
