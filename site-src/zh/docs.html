安装和设置

Tidytalk 需要 macOS 26 或更高版本、Apple 芯片的 Mac。

  1. 在 GitHub Releases 下载最新的 Tidytalk-x.y.z.dmg，打开后把 Tidytalk 拖进 Applications 文件夹。
  2. 安装包目前没有经过苹果公证，第一次打开会被系统拦下。打开"系统设置 › 隐私与安全性"，在页面底部点"仍要打开"；或者在终端执行： 
    xattr -dr com.apple.quarantine /Applications/Tidytalk.app
  3. 按首次启动的引导完成：
    • 授权麦克风：用于录音。
    • 授权辅助功能：用于监听快捷键，并把文字粘贴到光标处。
    • 配置 AI：填写 OpenAI 兼容接口的地址、API Key 和模型，默认 DeepSeek。可以跳过，跳过后直接输出识别结果。
    • 下载语音识别模型：约 240 MB，只需下载一次，之后识别不用联网。

Tidytalk 平时只在菜单栏显示图标，只有打开引导或设置窗口时才会出现在 Dock 里。设置、最近记录和输出语言都在菜单栏图标里。

按住说话

  1. 在任意输入框里放好光标。
  2. 按住 Option + Command 说话。屏幕底部会出现一个玻璃质感的指示器，随音量跳动。
  3. 说完松开，稍等片刻，整理好的文字出现在光标处。
  • 按住约 0.4 秒才开始录音，日常按 Option + Command + 某个键的快捷键不会误触发。
  • 按住期间按下其他键、点击鼠标或按 Esc，会取消本次录音。
  • 单次录音最长约 2 分钟，不足 0.5 秒的录音会被忽略。
  • 快捷键可以在"设置 › 说话输入"里换成 Control、Option、Command、Fn（🌐）、右侧 Option 或右侧 Command。选 Fn 时，要在"系统设置 › 键盘"里把"按下 🌐 键时"设为"无操作"，否则会同时弹出表情或听写。
  • 说话时指示器下方会显示实时文字，这只是预览，最终结果在松开后整段识别、整理再粘贴。
  • 当前没有可以输入的地方时（例如焦点在桌面或网页正文上），结果会放进剪贴板，而不是模拟粘贴。
  • 粘贴完成后，剪贴板会恢复成原来的内容，图片、文件和富文本也会完整恢复。

免按住录音

快速双击快捷键，开始录音后就可以松手，适合说较长的内容；再按一次快捷键结束，按 Esc 取消。录音期间打字、点击鼠标不会打断录音。说得很长时，Tidytalk 会边录边识别已经说完的部分，松开后很快就能出字。可以在"设置 › 说话输入"里关闭。

语音改写选中的文字

先选中一段文字，按住右侧 Option说出修改要求，例如"改得正式一点""缩短到一句话""翻译成英文"，松开后选中的文字会被替换成改写结果。

  • 需要配置 AI；选中的文字和修改要求会发送给 AI 服务。
  • 没有选中文字时会提示先选中；改写失败时原文不会改动。
  • 改写键可以在"设置 › 说话输入"里更换或关闭。

从其他应用控制

Tidytalk 能响应 tidytalk:// 开头的网址，可以在 Raycast、快捷指令、Karabiner、Stream Deck 里绑定：

网址作用
tidytalk://toggle开始说话输入，和双击快捷键一样不用按住；再打开一次结束
tidytalk://start / tidytalk://stop只开始 / 只结束
tidytalk://cancel取消这次录音
tidytalk://captions打开或关闭实时字幕；也可以用 captions/start、captions/stop

在终端或脚本里用 open -g tidytalk://toggle，焦点会留在正在打字的地方。如果打开网址时 Tidytalk 被切到了前台，它会把焦点还给原来的应用，文字照样粘贴到光标处。

识别模型

默认用 SenseVoice：体积小（约 240 MB）、速度快，中英文混说效果好。在"设置 › 识别模型"里可以换用其他模型，所有模型都在本机运行。

  • Qwen3-ASR（约 1 GB）：最准确，支持 30 种语言和 22 种中文方言，能直接认出词库里的人名和术语；20 秒的话约需 4 秒。
  • Fun-ASR-Nano（约 1 GB）：中文、英文、日文，准确度接近 Qwen3-ASR，速度稍快。
  • Whisper Turbo（约 1 GB）：约 99 种语言，适合小语种；中文会漏字。
  • Apple 系统识别：macOS 自带，不用下载；按系统语言识别，中英文混说效果一般。

点"下载并使用"后可以继续用：下载完成前一直用当前的模型，下载好后自动换用。说话输入、实时字幕和转写文件都使用这里选的模型。

实时字幕

收听电脑播放的声音（视频、网课、视频会议），在屏幕底部显示字幕。只录电脑输出的声音，不录麦克风；声音同样只在本机识别。

  • 打开和关闭：按 ⌃⌥C（Control + Option + C），或在菜单栏菜单的"实时字幕"一组里选"开始收听"。第一次打开时，macOS 会询问是否允许 Tidytalk 录制系统音频。收听期间菜单栏图标右上角有一个橙色圆点；关掉后，内存里的声音和文字全部清空。
  • 字幕条：一句一段，前面的句子淡一些。可以拖到任意位置，位置会被记住；没有声音 10 秒后自动隐藏，有声音再出现。鼠标移上去时右上角出现翻译、暂停、关闭三个按钮，关闭就是停止收听；点句子本身不会有任何操作，可以放心拖动。样式（深色或玻璃）和文字大小在"设置 › 实时字幕"里选。
  • 收听来源：默认收听全部声音（不含 Tidytalk 自己的提示音），也可以只听某个应用，在菜单的"收听来源"或"设置 › 实时字幕"里选。
  • 翻译：打开"翻译字幕"后，用"配置 AI"里的服务翻译，译文显示在原文下面；原文已经是目标语言的句子不翻译。默认"边听边翻译"：正在说的这句也会先翻出来，随说话内容更新，说完后换成整句的正式译文；关掉后改为每句说完再翻译，调用 AI 的次数更少。选 Ollama、LM Studio 或 Apple 智能时全程不联网，选云端服务时字幕文字会发送给该服务。
  • 粘贴刚才那段：收听时把光标放进输入框，按 ⌃⌥V，把最近一段话（从上一次超过 2 秒的停顿开始，最多 30 秒）按说话输入的设置整理后粘贴。也可以把鼠标移到字幕条上的某一句，点它右边出现的"粘贴"，从那句粘贴到最新。⌃⌥V 只在收听期间生效，没打开字幕时这个组合键留给其他应用使用。

一步步的设置方法见在 Mac 上给视频和会议加实时翻译字幕。

转写文件或链接

在菜单栏菜单里选"转写文件或链接…"：

  • 把音频或视频文件（MP3、M4A、WAV、MP4、MOV 等，最长 3 小时）拖进窗口，或点"选择文件…"。
  • 也可以粘贴视频链接（YouTube、B 站等）。第一次转写链接时，会先从 yt-dlp 的官方 GitHub 下载这个开源工具（约 35 MB）并按发布页公布的校验值核对，之后每两周自动更新；之后只下载链接里的音频，转写完就删除。仅限你有权使用的内容。
  • 按停顿切成一句句，带时间显示。可以拷贝全文，或导出成纯文本（.txt）、字幕（.srt）或 Markdown。
  • 使用"设置 › 识别模型"里选的模型，在本机识别。

整理效果

整理只做删减和修正，不改变你说的内容：

  • 删除没有实际含义的填充词，例如：嗯、呃、那个、就是说、um、uh、like。
  • 删除重复的词句和口误；中途改口时，只保留改口后的说法。
  • 补全标点，必要时断句。
  • 不总结、不补充，保持原文的语气；句中的英文单词和术语原样保留。
  • 即使你说的话听起来像指令（比如"帮我写一封邮件"），也只会被整理成文字，不会被执行。
你说的输出
嗯那个我想问一下就是这个 API 的那个 rate limit 呃是多少我想问一下这个 API 的 rate limit 是多少？
项目要延期到下周三，不对，是下周四项目要延期到下周四。

在"设置 › 配置 AI"里关闭"整理文字"后，直接输出识别结果，应用完全离线工作。AI 服务超时、连不上或返回异常时，会粘贴识别原文并给出提示。

整理强度和模式

都在"设置 › 配置 AI › 整理方式"里切换。

强度效果
轻度只补全标点、删除"嗯、呃"这类语气词，其余原话保留
标准（默认）删除填充词和口误，补全标点
深度在标准基础上进一步精简啰嗦、重复的表达，但不改变原意
模式效果
标准（默认）删除填充词、修正口误、补全标点，保持原意
聊天（口语）保持口语化的语气，保留句末语气词
邮件（书面）使用书面表达，句子完整
代码（保留术语）严格保留术语、命令、文件名和符号，不转换标点

输出语言

默认"与原文相同"。选择其他语言后，说中文或英文，整理时直接翻译，例如说中文、粘贴出英文邮件。支持英文、简体中文、繁体中文、日文、韩文、法文、德文和西班牙文。

  • 在"设置 › 配置 AI › 整理方式"里修改，也可以在菜单栏图标的"输出语言"子菜单里快速切换。
  • 翻译和整理在同一次请求里完成，速度和只整理差不多；词库和整理模式同样生效。
  • 翻译需要开启"整理文字"，请求失败时粘贴原文。

更多例子见说中文，直接出英文。

本机大模型

Tidytalk 用 OpenAI 兼容协议连接 AI 服务，所以也能接本机运行的模型，文字不会离开电脑：

  1. 安装 Ollama 并下载一个模型，例如 ollama pull qwen2.5:7b；或者在 LM Studio 里下载并加载模型，打开本地服务。
  2. 在"设置 › 配置 AI"顶部选 Ollama 或 LM Studio，确认模型名后保存。要换回 DeepSeek、OpenAI 等云端接口，选云端。本机模型不需要 API Key，超时默认放宽到 60 秒。
  3. 点"测试连接"确认可用。

Qwen3、DeepSeek-R1 这类会"思考"的推理模型也能用：Tidytalk 会请求它跳过思考，万一还是带了思考过程，也会自动去掉。效果取决于模型大小。小模型对"只整理、不回答"和自定义规则的遵守不如云端模型稳定，建议用 7B 左右或更大的模型。详见完全离线的 Mac 语音输入。

Apple 智能

支持 Apple 智能的 Mac，在"设置 › 配置 AI"里选 Apple 智能，就用系统自带的模型整理和翻译，不需要 API Key，文字不会离开这台 Mac。需要先在系统设置里打开 Apple 智能；这台 Mac 不支持或还没打开时，这一项会变灰并写明原因。

词库

都在"设置 › 词库"里。

常用词

每行一个人名、产品名或专业术语，这些词最容易识别错。识别模型选 Qwen3-ASR 时，识别阶段就能认对这些词；它们还会放进 AI 整理的提示里，让模型把读音相近的错误识别改成正确写法，例如"森斯沃伊斯"改为"SenseVoice"（这一步需要开启"整理文字"）。关闭整理时，Tidytalk 也会在本机纠正和词库里"差一点"的词：大小写或空格不同（"github" → "GitHub"、"chat gpt" → "ChatGPT"），较长的英文词拼错一个字母（"Kubernetis" → "Kubernetes"），以及三个字以上读音完全相同的中文词（"张三峰" → "张三丰"）。网址、邮箱和文件路径里的词不会被改动。

固定替换

识别结果里出现某个词时，总是替换成指定写法，例如"克劳德"总是替换成"Claude"。英文不区分大小写，只匹配完整单词。在本机处理，关闭整理时也生效。在菜单栏图标的"最近记录"里选一条，点"加入词库…"，可以直接把识别错的词加进来。

自动学词

粘贴后，如果你在同一个输入框里把某个词改成了别的写法（例如把"克劳德"改成"Claude"），会在菜单栏的"发现 N 处改动"和"设置 › 词库"顶部列出来，点"加入词库"才会加入。只在粘贴后的一分半钟内比较，不保存任何内容；不需要的话，在词库页底部关掉。

快捷短语

例如"我的邮箱"对应完整的邮箱地址。整句话只说这个短语时，直接输出设置好的内容；句子中间提到这个短语不会被替换。

自定义规则

每行写一条自己的写法要求，例如"金额一律用阿拉伯数字""产品名写作 Tidytalk"。AI 整理和语音改写时都会遵守；规则只影响写法，不会让 AI 补充原文没有的内容。最多 20 条。

中英文排版规范

在本机自动处理：中文与英文、数字之间加空格；中文后面的标点统一为全角；全角字母和数字转为半角。数字里的小数点、文件名、网址等不受影响。可以在"设置 › 通用"里关闭。

最近记录

最近 20 次的结果记在内存里。在菜单栏图标的"最近记录"里，可以重新粘贴或拷贝、拷贝未经整理的识别原文、用其他模式或语言"重新整理"并粘贴到当前输入框，或者把识别错的词"加入词库"。记录不写入磁盘，退出应用即清空。

支持的语言

说话时不需要选择语言，识别会自动判断。默认的 SenseVoice 模型支持：

  • 中文普通话，包括句中夹杂的英文单词和技术术语
  • 英文
  • 日文
  • 韩文
  • 粤语（识别结果用简体字，保留粤语的说法）

其他语言和方言可以在"设置 › 识别模型"里换模型：Qwen3-ASR 支持 30 种语言和 22 种中文方言（如四川话、东北话、吴语、闽南语），Whisper Turbo 支持约 99 种语言。也可以用一种语言说，再设置输出语言，写成另一种语言。界面支持简体中文和英文，跟随系统语言。

常见问题

情况原因和处理
提示"整理失败，已粘贴原文"AI 服务连不上、超时或返回异常。检查网络，在"设置 › 配置 AI"里点"测试连接"。
提示"没有听到内容"没有识别到内容。在"设置 › 说话输入"里检查麦克风。
按快捷键没反应缺少辅助功能权限，在"设置 › 通用 › 权限"里授权。
打开时提示无法验证开发者安装包还没有公证，在"系统设置 › 隐私与安全性"里点"仍要打开"。

辅助功能一直显示未授权

系统设置里已经打开了 Tidytalk 的开关，应用却仍显示未授权，通常是列表里留着旧版本的条目。在"系统设置 › 隐私与安全性 › 辅助功能"里选中 Tidytalk 点"−"删除，再回到 Tidytalk 点"授权"重新添加；或者在终端执行：

tccutil reset Accessibility app.tidytalk.Tidytalk

所有设置都保存在 ~/.tidytalk.json（API Key 存在 macOS 钥匙串里，不写进文件），也可以直接编辑，字段说明见配置文件文档。

卸载

把 Tidytalk 拖进废纸篓只会删除应用本身，语音识别模型、配置和授权记录都会留在电脑上。完整卸载：先退出 Tidytalk（开启过开机自动启动的话先关掉），把应用拖进废纸篓，再在终端执行：

rm -rf ~/Library/Application\ Support/Tidytalk
rm -f ~/.tidytalk.json
security delete-generic-password -s app.tidytalk.Tidytalk -a ai.api_key
rm -rf ~/Library/Caches/app.tidytalk.Tidytalk ~/Library/HTTPStorages/app.tidytalk.Tidytalk
defaults delete app.tidytalk.Tidytalk
tccutil reset All app.tidytalk.Tidytalk

这几行依次删除语音识别模型（SenseVoice 约 240 MB，其他模型各约 1 GB）和 yt-dlp、配置文件、钥匙串里的 API Key、联网缓存、系统偏好，以及麦克风、辅助功能和录制系统音频的授权。打算以后重装、想保留设置的话，可以不删 ~/.tidytalk.json。
