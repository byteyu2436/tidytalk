# 使用指南

## 它是什么，不是什么

Tidytalk 是**段落式**的：说完一整段，松开按键，一次性输出整理好的文字。适合写消息、写文档、记想法这类"想清楚再说"的场景。

它**不是**实时逐字输入法，不会边说边往输入框里打字，也不替代系统输入法。说话时指示器下方会显示识别到的文字，方便确认自己说了什么，但这只是预览；最终结果在松开后整段识别、整理再粘贴。

## 按住说话

1. 在任意输入框里放好光标。
2. 按住 Option + Command 说话。屏幕底部会出现一个玻璃质感的指示器，随音量跳动。
3. 说完松开，稍等片刻，文字出现在光标处。

<p align="center"><img src="images/settings-recording.png" width="520" alt="设置 › 说话输入"></p>

细节：

- 按住超过约 0.4 秒才开始录音，日常按 Option + Command + 某个键的快捷键不会误触发。
- 按住期间按下其他键、其他修饰键、Esc，或点击鼠标，会取消本次录音。
- 已经按着 Shift、Control 或 Fn 时再按，不会触发。
- 单次录音最长约 2 分钟，不足 0.5 秒的录音会被忽略。
- 快捷键可以在"设置 › 说话输入 › 快捷键"里换成 Control、Option、Command、Fn（🌐）、右侧 Option 或右侧 Command。选 Fn 时，需要在"系统设置 › 键盘"里把"按下 🌐 键时"设为"无操作"，否则会同时弹出表情或听写。
- 麦克风默认跟随系统，也可以在"设置 › 说话输入"里指定外接耳机、会议麦克风等；指定的设备未连接时自动用系统默认麦克风。
- 开始、结束录音时有提示音，可以在设置里关闭。
- 说话时，指示器下方用灰色小字显示识别到的内容：放得下时居中，说得多了最新的文字在右边，前面的向左淡出。预览在本机完成，每 0.6 秒刷新一次，可以在设置里关闭。
- 当前没有可以输入的地方时（例如焦点在桌面、网页正文、列表上），不会模拟粘贴，而是把结果放进剪贴板并提示"已拷贝到剪贴板"。无法判断焦点的应用会照常粘贴。

### 免按住录音

快速双击快捷键，开始录音后就可以松手，适合说较长的内容；再按一次快捷键结束，按 Esc 取消。录音期间打字、点击鼠标不会打断录音。说得很长时，会边录边识别已经说完的部分，松开后很快出字。可以在设置里关闭。

### 语音改写选中的文字

先选中一段已有的文字，按住改写键（默认右侧 Option）说出修改要求，例如"改得正式一点""缩短到一句话""翻译成英文"，松开后选中的文字会被替换成改写结果。改写时指示器上显示"改写"，周围有彩色光点向外飘散。

- 需要配置 AI；选中的文字和修改要求会发送给 AI 服务。
- 优先通过辅助功能直接读取选中的文字；读不到时（例如部分网页和 Electron 应用）会模拟一次 Cmd+C，读完立即恢复剪贴板。
- 没有选中文字时提示"请先选中要改写的文字"；改写失败时原文不会改动。
- 改写键可以在设置里更换或关闭，不能和按住说话的键相同。

### 从其他应用控制

Tidytalk 能响应 `tidytalk://` 开头的网址，可以在 Raycast、快捷指令、Karabiner 里绑定：

| 网址 | 作用 |
| --- | --- |
| `tidytalk://toggle` | 开始说话输入（和双击快捷键一样不用按住），再打开一次结束 |
| `tidytalk://start`、`tidytalk://stop` | 只开始、只结束 |
| `tidytalk://cancel` | 取消这次录音 |
| `tidytalk://captions` | 开关实时字幕；也可以用 `captions/start`、`captions/stop` |

在终端或脚本里用 `open -g tidytalk://toggle`，焦点会留在正在打字的地方。

## 识别模型

默认用 SenseVoice：体积小（约 240 MB）、速度快，中英文混说效果好。在"设置 › 识别模型"里可以换用其他模型，所有模型都在本机运行：

| 模型 | 大小 | 特点 |
| --- | --- | --- |
| SenseVoice（默认） | 约 240 MB | 速度最快，中文、英文、日文、韩文、粤语 |
| Qwen3-ASR | 约 1 GB | 最准确，支持 30 种语言和 22 种中文方言，能直接认出词库里的人名和术语；20 秒的话约需 4 秒 |
| Fun-ASR-Nano | 约 1 GB | 中文、英文、日文，准确度接近 Qwen3-ASR，速度稍快 |
| Whisper Turbo | 约 1 GB | 约 99 种语言，适合小语种；中文会漏字 |
| Apple 系统识别 | 系统自带 | macOS 自带，按系统语言识别，中英文混说效果一般 |

还没下载的模型，点"下载并使用"后开始下载，下载完成后自动换用，期间继续用当前的模型。不用的模型可以点旁边的垃圾桶删除。说话输入、实时字幕和转写文件都使用这里选的模型。

## 实时字幕

收听电脑播放的声音（视频、网课、视频会议），在屏幕底部显示字幕。只录电脑输出的声音，不录麦克风；声音同样只在本机识别。

- **打开和关闭**：按 **⌃⌥C**（Control + Option + C），或在菜单栏菜单的"实时字幕"一组里选"开始收听"。第一次打开时，macOS 会询问是否允许 Tidytalk 录制系统音频。收听期间菜单栏图标右上角有一个橙色圆点；关掉后，内存里的声音和文字全部清空。
- **字幕条**：一句一段，前面的句子淡一些。可以拖到任意位置，位置会被记住；没有声音 10 秒后自动隐藏，有声音再出现。鼠标移上去时右上角出现翻译、暂停、关闭三个按钮；点句子本身不会有任何操作，可以放心拖动，关闭就是停止收听。样式（深色或玻璃）和文字大小在"设置 › 实时字幕"里选。
- **收听来源**：默认收听全部声音（不含 Tidytalk 自己的提示音），也可以只听某个应用，在菜单的"收听来源"或"设置 › 实时字幕"里选。
- **翻译**：打开"翻译字幕"后，用"配置 AI"里的服务翻译，译文显示在原文下面；原文已经是目标语言的句子不翻译。默认"边听边翻译"：正在说的这句也会先翻出来，随说话内容更新，说完后换成整句的正式译文；关掉后改为每句说完再翻译，调用 AI 的次数更少。选 Ollama、LM Studio 或 Apple 智能时全程不联网，选云端服务时字幕文字会发送给该服务。
- **粘贴刚才那段**：收听时把光标放进输入框，按 **⌃⌥V**，把最近一段话（从上一次超过 2 秒的停顿开始，最多 30 秒）按说话输入的规则整理后粘贴。也可以把鼠标移到字幕条上的某一句，点它右边出现的"粘贴"，从那句粘贴到最新。⌃⌥V 只在收听期间生效，没打开字幕时这个组合键留给其他应用使用。说话输入正在录音或处理时按 ⌃⌥V，会响一声提示，不会打断当前的输入。

## 转写文件或链接

在菜单栏菜单里选"转写文件或链接…"：

- 把音频或视频文件（MP3、M4A、WAV、MP4、MOV 等，最长 3 小时）拖进窗口，或点"选择文件…"。
- 也可以粘贴视频链接（YouTube、B 站等）。第一次转写链接时，会先从 yt-dlp 的官方 GitHub 下载这个开源工具（约 35 MB），并按同一个发布页公布的 SHA-256 校验，能发现下载损坏，但防不了发布页本身被篡改。下载后超过 14 天会自动更新到最新版，免得视频网站改版后用不了。之后只下载链接里的音频，转写完就删除。仅限你有权使用的内容。
- 按停顿切成一句句，带时间显示。可以拷贝全文，或导出成纯文本（.txt）、字幕（.srt）或 Markdown。
- 使用"设置 › 识别模型"里选的模型，在本机识别，同样套用固定替换和中英文排版。

## 整理效果

整理只做删减和修正，不改变你说的内容：

- 删除没有实际含义的填充词，例如：嗯、呃、那个、就是说、um、uh、like。
- 删除重复的词句和口误；中途改口时，只保留改口后的说法。
- 补全标点，必要时断句。
- 不总结、不补充，保持原文的语气；句中的英文单词和术语原样保留。默认保持原文的语言，需要时可以设置[输出语言](#输出语言)。
- 即使你说的话听起来像指令（比如"帮我写一封邮件"），也只会被整理成文字，不会被执行。

| 你说的 | 输出 |
| --- | --- |
| 嗯那个我想问一下就是这个 API 的那个 rate limit 呃是多少 | 我想问一下这个 API 的 rate limit 是多少？ |
| 项目要延期到下周三，不对，是下周四 | 项目要延期到下周四。 |

在"设置 › 配置 AI"里关闭"整理文字"后，直接输出识别结果，应用完全离线工作。

### 整理强度

| 强度 | 效果 |
| --- | --- |
| 轻度 | 只补全标点、删除"嗯、呃"这类语气词，其余原话保留 |
| 标准 | 删除填充词和口误，补全标点（默认） |
| 深度 | 在标准基础上进一步精简啰嗦、重复的表达，但不改变原意 |

### 整理模式

| 模式 | 效果 |
| --- | --- |
| 标准 | 删除填充词、修正口误、补全标点，保持原意（默认） |
| 聊天（口语） | 保持口语化的语气，保留句末语气词 |
| 邮件（书面） | 使用书面表达，句子完整 |
| 代码（保留术语） | 严格保留术语、命令、文件名和符号，不转换标点 |

强度和模式在"设置 › 配置 AI › 整理方式"里切换。因为整理只做删减和修正，不同模式之间的差别主要体现在语气词、标点和个别用词上。

### 输出语言

默认"与原文相同"。选择其他语言后，说中文或英文，整理后直接输出译文，例如说中文、粘贴出英文邮件。支持 English、简体中文、繁體中文、日本語、한국어、Français、Deutsch、Español。

- 在"设置 › 配置 AI › 整理方式"里修改，也可以在菜单栏图标的"输出语言"子菜单里快速切换。
- 翻译和整理在同一次请求里完成，速度和只整理差不多。词库和整理模式同样生效，例如用"邮件（书面）"模式翻译成英文。
- 翻译依赖整理：关闭整理、网络失败或结果异常时，粘贴识别原文并给出提示。
- 说的内容即使是问题或指令，也只会被翻译，不会被回答。

### 本机大模型（完全离线）

AI 整理使用 OpenAI 兼容协议，也可以接本机运行的模型服务，文字不会离开电脑：

1. 安装 [Ollama](https://ollama.com) 并下载一个模型，例如 `ollama pull qwen2.5:7b`；或者在 LM Studio 里下载并加载一个模型，打开本地服务。
2. 在"设置 › 配置 AI"顶部选 **Ollama** 或 **LM Studio**，确认模型名后保存。要换回 DeepSeek、OpenAI 等云端接口，选**云端**。本机模型不需要 API Key，超时默认放宽到 60 秒。
3. 点"测试连接"确认可用。

Qwen3、DeepSeek-R1 这类会"思考"的推理模型也能用：Tidytalk 会请求它跳过思考，万一还是带了思考过程，也会自动去掉。效果取决于模型大小。小模型对"只整理、不回答"和自定义规则的遵守可能不如云端模型稳定，建议用 7B 左右或更大的模型。

### Apple 智能

支持 Apple 智能的 Mac，在"设置 › 配置 AI"里选 **Apple 智能**，就用系统自带的模型整理和翻译，不需要 API Key，文字不会离开这台 Mac。需要先在"系统设置 › Apple 智能与 Siri"里打开 Apple 智能；这台 Mac 不支持或还没打开时，这一项会变灰并写明原因。

都在"设置 › 词库"里。

### 常用词

每行一个人名、产品名或专业术语，这些词最容易识别错。识别模型选 Qwen3-ASR 时，识别阶段就会优先认出这些词。SenseVoice 本身不支持热词，所以常用词还会放进 AI 整理的提示里，让模型把读音相近的错误识别改成正确写法，例如"森斯沃伊斯"改为"SenseVoice"。读音不像或拿不准的地方保持原文。需要开启整理文字。

关闭整理时也会在本机纠正和词库里"差一点"的词：大小写或空格不同（github → GitHub、chat gpt → ChatGPT），较长的英文词拼错一个字母（Kubernetis → Kubernetes），以及三个字以上读音完全相同的中文词（张三峰 → 张三丰）。网址、邮箱和文件路径里的词不会被改动。

### 固定替换

识别结果里出现某个词时总是替换成指定写法，例如"克劳德"总是替换成"Claude"。英文不区分大小写、只匹配完整单词。在本机处理，关闭整理时也生效。

在菜单栏图标的"最近记录"里选一条，点"加入词库…"，可以直接把识别错的词加进替换表和常用词。

### 自动学词

粘贴后，如果你在同一个输入框里把某个词改成了别的写法（例如把"克劳德"改成"Claude"），屏幕底部会提示一下，并在菜单栏的"发现 N 处改动"和"设置 › 词库"顶部列出来。点"加入词库"才会加进替换表和常用词，点"忽略"就不再提示。整句重写、只加删内容、只改标点都不算。需要辅助功能能读到这个输入框（大多数原生应用可以），只在粘贴后的一分半钟内比较，不保存任何内容；不需要的话，在词库页底部关掉。

### 快捷短语

例如"我的邮箱" → 完整的邮箱地址。整句话只说这个短语时，直接输出设置好的内容，不经过 AI；句子中间提到这个短语不会被替换。

### 自定义规则

每行写一条自己的写法要求，例如"金额一律用阿拉伯数字""称呼对方统一用'您'""产品名写作 Tidytalk"。AI 整理和语音改写时都会遵守；规则只影响写法，不会让 AI 补充原文没有的内容。最多 20 条，需要开启整理文字。

## 中英文排版规范

在本机自动处理，不需要联网：中文与英文、数字之间加空格；中文后面的标点统一为全角；全角字母和数字转为半角；全角标点两侧不留空格。数字里的小数点、文件名、网址等不受影响。可以在"设置 › 说话输入"里关闭。

## 最近记录

最近 20 次的结果记在内存里，可以在菜单栏图标的"最近记录"里：

- 重新粘贴或拷贝，适合误粘贴或想再用一次的时候；
- 拷贝未经整理的识别原文；
- "重新整理"：换成其他整理模式或翻译成其他语言，结果直接粘贴到当前输入框，不用再说一遍（需要配置 AI）；
- "加入词库…"：把识别错的词加进替换表和常用词。

记录不写入磁盘，退出应用即清空；也可以在设置里关闭或随时清空。

## 开机自动启动

在"设置 › 通用"里打开，使用系统的登录项。系统要求确认时，按提示到"系统设置 › 通用 › 登录项"里允许。

## 支持的语言

说话时不需要选择语言，识别会自动判断：

- 中文普通话，包括句中夹杂英文单词和技术术语（如 demo、API、SDK）
- 英文
- 日文
- 韩文
- 粤语（识别结果用简体字，保留粤语的说法，例如"听日""带埋"）

不支持其他语言（例如法语、德语、西班牙语）和其他方言。需要输出其他语言时，可以用中文或英文说，再通过"输出语言"翻译。

界面支持简体中文和英文，跟随系统语言：系统首选语言是中文时显示中文，其他语言显示英文。AI 整理的提示词固定为中文，对说英文、日文等的内容同样有效。

## 出错时会怎样

| 情况 | 处理 |
| --- | --- |
| 网络不可用、AI 服务超时或报错 | 直接粘贴识别原文，并提示"整理失败，已粘贴原文" |
| 整理结果明显异常（比原文长很多或短很多） | 视为整理失败，粘贴识别原文 |
| 没有识别到内容 | 提示"没有听到内容"，不粘贴 |
| 等 AI 整理时不想要了 | 按 Esc 取消，不会粘贴 |
| 录音中途麦克风断开（例如拔掉耳机、蓝牙耳机断连） | 换到另一个麦克风后继续录。一直没有恢复时，照常粘贴断开前录到的部分，并提示"后面的话没有录到"；语音改写则不执行，提示再说一次 |
| 语音识别模型文件损坏 | 设置里该模型显示"加载失败"和"重新下载"按钮 |
| 配置文件格式错误 | 菜单栏菜单最上面提示，点它打开文件修改；修好前设置改动不会保存 |
| 缺少权限 | 提示需要授权的项目 |

### 辅助功能显示未授权

系统设置里已经打开了 Tidytalk 的开关，应用却仍显示未授权，通常是列表里留着旧版本的条目。在"系统设置 › 隐私与安全性 › 辅助功能"里选中 Tidytalk 点"−"删除，再回到 Tidytalk 点"授权"重新添加；或者在终端执行：

```bash
tccutil reset Accessibility app.tidytalk.Tidytalk
```

## 卸载

把 Tidytalk 拖进废纸篓只会删除应用本身，语音识别模型、配置文件和授权记录都会留在电脑上，需要手动清理：

1. 如果开启了开机自动启动，先在"设置 › 通用"里关掉，然后在菜单栏图标里选"退出 Tidytalk"。
2. 把"应用程序"文件夹里的 Tidytalk 拖进废纸篓。
3. 在终端里执行：

   ```bash
   rm -rf ~/Library/Application\ Support/Tidytalk
   rm -f ~/.tidytalk.json
   security delete-generic-password -s app.tidytalk.Tidytalk -a ai.api_key
   rm -rf ~/Library/Caches/app.tidytalk.Tidytalk ~/Library/HTTPStorages/app.tidytalk.Tidytalk
   defaults delete app.tidytalk.Tidytalk
   tccutil reset All app.tidytalk.Tidytalk
   ```

| 位置 | 内容 |
| --- | --- |
| `~/Library/Application Support/Tidytalk/` | 语音识别模型（SenseVoice 约 240 MB，其他模型各约 1 GB），以及转写链接用的 yt-dlp |
| `~/.tidytalk.json` | 设置、AI 接口地址、词库、快捷短语、自定义规则 |
| 钥匙串里的 `app.tidytalk.Tidytalk` | API Key |
| `~/Library/Caches/app.tidytalk.Tidytalk/`、`~/Library/HTTPStorages/app.tidytalk.Tidytalk/` | 系统为联网请求留下的缓存 |
| `~/Library/Preferences/app.tidytalk.Tidytalk.plist` | 系统保存的窗口位置等偏好，用 `defaults delete` 删除 |
| 系统设置里的麦克风、辅助功能、录制系统音频授权 | 用 `tccutil reset` 清除，也可以在"系统设置 › 隐私与安全性"里选中 Tidytalk 点"−"移除 |

打算以后重装、想保留设置和词库的话，可以不删 `~/.tidytalk.json`。它是隐藏文件，在访达里按 Command + Shift + 句号可以显示。
