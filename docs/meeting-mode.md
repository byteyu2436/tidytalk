# 会议记录和主窗口：功能清单与核实记录

2026-10-23 新增。每一项写明怎么核实；发版前逐条确认，更新日志从这份清单里写。

状态：已完成 → 已核实；"待手动核实"表示要在真机上实际开会、外放、插拔耳机才能确认，自动化测不到。

## 能做到的程度

| 情况 | 结果 |
| --- | --- |
| "我"和"对方" | 麦克风和电脑声音是两路独立的音频，同时说话也能完全分开 |
| 对方有几个人 | 会后用本机的说话人分离（pyannote 分段 + CAM++ 声纹）分成说话人 1、2、3，可以改名，可以指定人数重新分 |
| 对方几个人同时说 | 标出"同时在说"和参与的人；这段文字是混在一起识别的（本机没有能拆开重叠人声的模型） |
| 同一个人和自己的回声叠在一起 | 识别器可能认不出，这一段会缺字（极端情况，见 M8 的测试） |

## 核实记录

2026-10-23：单元测试全部通过（核心 + 应用层）。`--meeting-test` 用官方四人录音做对方、一段单人录音做自己，跑了四种情况：正常、麦克风混入回声、对方重叠、麦克风里只有回声。说话人分离在这台 Mac 上的速度约为音频长度的 6–11%。用模拟 AI 服务测了总结的三条路径。主窗口和设置页都截图看过（中英文）。

麦克风和电脑声音的实时采集、系统回声消除、权限提示、快捷键和菜单，需要装上应用、真机开会时手动核实。
