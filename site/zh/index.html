macOS 段落式语音输入 · 免费开源

按住说话，松开就是整理好的文字

Tidytalk 在你的 Mac 上识别语音，用 AI 去掉"嗯、那个、就是说"这类口头禅，修正口误和标点，再把文字粘贴到光标处。微信、邮件、备忘录、代码编辑器，能打字的地方都能用。

整理

三步完成输入

不用切换输入法，也不用对着屏幕一个字一个字地改。

  1. 按住 Option + Command

    光标放在任意输入框里，按住快捷键，屏幕底部出现录音指示器。

  2. 说一段话

    想到哪说到哪，说错了直接改口，指示器下方会显示实时文字。

  3. 松开，文字就到了

    整理好的文字出现在光标处，原来剪贴板里的内容也会还原。

为想清楚再说的人设计

只删口头禅和口误，不总结、不补充，保留你自己的说法。

声音不出这台 Mac

用 SenseVoice 在本机识别，自动判断中文、英文、日文、韩文和粤语，中文里夹英文也没问题。

只整理，不改写

删掉口头禅和重复，中途改口只留最后的说法，补全标点。听起来像指令的话也只会被整理成文字。

AI 服务随你选

DeepSeek、OpenAI 等兼容接口都能用，也能接 Ollama、LM Studio 本机模型完全离线。不想用 AI，关掉整理即可。

说中文，出英文

选好输出语言，整理时顺便翻译。支持英文、简体、繁体、日文、韩文、法文、德文和西班牙文。

选中文字，用嘴改

选中一段文字，按住右侧 Option 说"改得正式一点""缩短到一句话"，原文直接被替换成改写结果。

词库和快捷短语

记住常用的人名、产品名，固定替换容易识别错的词；只说"我的邮箱"就输出完整地址。

适合你的工作方式

写提示词、回邮件、记想法，用你习惯的语言说。

程序员

用语音写给 AI 编程工具的提示词、提交信息和代码注释，技术名词原样保留。

一分钟设置好

首次打开有引导：授权麦克风和辅助功能、填写 AI 接口（可以跳过）、下载语音识别模型。

隐私

  • 录音和语音识别都在你的 Mac 上完成，声音不会上传。
  • 开启整理文字时，识别出的文字会发送给你自己配置的 AI 服务；用本机模型或关闭整理，文字也不会离开电脑。
  • API Key 等设置保存在本机的 ~/.tidytalk.json，只有你自己能读写。
  • 最近记录只保存在内存中，退出应用就清空。
  • 代码完全开源，可以在 GitHub 上查看每一行。

安装

  1. 在 GitHub Releases 下载最新的 Tidytalk-x.y.z.dmg。
  2. 打开安装包，把 Tidytalk 拖进 Applications 文件夹。
  3. 按引导完成设置，第一次需要下载约 240 MB 的语音识别模型。

安装包目前没有经过苹果公证，第一次打开会被系统拦下。打开"系统设置 › 隐私与安全性"，在页面底部点"仍要打开"；或者在终端执行：

xattr -dr com.apple.quarantine /Applications/Tidytalk.app

常见问题

Tidytalk 收费吗？

Tidytalk 免费开源，使用 MIT 许可证。如果整理文字时用 DeepSeek、OpenAI 等云端 AI，需要你自己的 API Key，费用由服务商收取；改用 Ollama、LM Studio 等本机模型，或者关闭整理，就完全不花钱。

需要联网吗？

第一次启动要联网下载约 240 MB 的语音识别模型，之后语音识别完全离线。用云端 AI 整理文字时需要联网；用本机模型或关闭整理时，整个应用都可以离线使用。

支持哪些语言？

说话时自动判断语言，支持中文普通话（可以夹杂英文单词）、英文、日文、韩文和粤语。整理后还可以翻译成英文、简体中文、繁体中文、日文、韩文、法文、德文或西班牙文。界面支持简体中文和英文。

我的声音和文字会被上传吗？

声音不会。录音和语音识别都在你的 Mac 上完成。开启整理文字时，识别出的文字会发送给你自己配置的 AI 服务；用本机模型或关闭整理，文字也不会离开电脑。

和 macOS 自带的听写有什么不同？

系统听写会边说边把话逐字打出来。Tidytalk 是段落式的：等你说完一整段，去掉"嗯、那个"这类口头禅和口误，补好标点，再一次性输出，适合写消息、邮件和文档。

支持 Windows 或 Intel 芯片的 Mac 吗？

目前只支持 macOS 26 或更高版本、Apple 芯片（M 系列）的 Mac。

第一次打开时提示无法验证开发者怎么办？

安装包目前没有经过苹果公证。打开"系统设置 › 隐私与安全性"，在页面底部点"仍要打开"；或者在终端执行 xattr -dr com.apple.quarantine /Applications/Tidytalk.app，之后就能直接打开。
