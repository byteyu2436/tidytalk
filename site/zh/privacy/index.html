隐私说明

Tidytalk 不需要账号，没有统计、追踪、广告和崩溃上报。声音始终在你的 Mac 上识别。这一页写明 Tidytalk 在本机存了什么、什么时候联网，以及哪些文字会发给谁。

更新于 2026-10-28

简单来说

  • 声音不上传。说话输入、实时字幕、会议记录、文件转写，都在这台 Mac 上识别。
  • 文字只发给你自己选的 AI 服务。选本机模型（Ollama、LM Studio）或 Apple 智能时，文字也不离开这台 Mac；关闭"整理文字"时直接输出识别结果。
  • 开发者看不到你的声音、文字和使用情况。Tidytalk 没有自己的服务器。
AI 服务声音文字
本机模型（Ollama、LM Studio）或 Apple 智能留在本机留在本机
关闭"整理文字"留在本机留在本机（识别原文）
云端 AI 服务（例如 DeepSeek、OpenAI）留在本机发送给你选的服务

声音

  • 说话输入：只在你按住快捷键（或双击开始免按住录音）时录音。录音只放在内存里，识别完就丢掉，不写入磁盘。
  • 实时字幕：收听电脑播放的声音。声音和字幕文字只在内存里，关掉字幕或退出 Tidytalk 就清空。
  • 会议记录：同时录下麦克风和电脑的声音，录音和文字保存在这台 Mac 上（见下面），可以只删录音、保留文字，也可以整场删除；设置里可以关掉"会后保留录音"。
  • 文件和链接转写：在本机识别。

会发给 AI 服务的文字

只有在你打开对应的功能、并在"设置 › AI 服务"里选了服务以后才会发送：

  • 整理文字：识别出的文字，以及词库里的常用词和自定义规则（让 AI 照着写）。
  • 语音改写：你选中的文字和你说的修改要求。
  • 字幕翻译：每一句字幕，加上前面几句作为上下文。
  • 会议总结：整场会议的文字和说话人的名字。默认不会自动总结，点紫色的"生成总结"按钮时才发送，按钮上方写明会发给哪个服务。

发给云端服务的文字，按那个服务自己的隐私政策处理。API Key 存在 macOS 钥匙串里，只发给你填写的接口地址。

什么时候联网

什么时候连到哪里做什么
第一次下载识别模型或说话人模型Hugging Face；下载不了时改用 HF-Mirror下载模型文件
启动时检查更新（每天最多一次），或手动检查GitHub（api.github.com）读取最新的版本号和更新说明；可以在"设置 › 通用"里关闭自动检查
第一次转写链接，之后每 14 天GitHub 上 yt-dlp 的发布页下载开源工具 yt-dlp 和它的校验值
转写一个链接链接所在的视频网站由 yt-dlp 下载音频和封面图
用 AI 服务时你填写的接口地址（本机模型是这台 Mac 上的 Ollama 或 LM Studio）发送上面列出的文字
用"Apple 系统识别"时ApplemacOS 可能下载语言资源，由系统管理

下载文件和检查更新时，对方能看到你的 IP 地址，这是联网本身决定的。除了这张表里的情况，Tidytalk 不联网。

保存在这台 Mac 上的内容

位置内容
~/.tidytalk.json设置、AI 接口地址、词库、快捷短语、自定义规则。只有你自己能读写
钥匙串里的 app.tidytalk.TidytalkAPI Key
~/Library/Application Support/Tidytalk/识别模型、说话人模型、yt-dlp；会议记录（Meetings/，文字和录音）；转写记录（Transcriptions/，文字，以及链接下载的音频和封面图）；说话记录（Dictations/，整理后的文字、识别原文和时间；语音改写时是你说的修改要求和改好的文字）。转写本机文件时只记下原文件的位置，不复制。不记录粘贴到了哪个应用
系统偏好设置里的 app.tidytalk.Tidytalk窗口位置、界面语言、是否看过设置引导、上次检查更新的时间和最新的版本号、录制系统音频是否允许过

会议、转写和说话记录的文件只有当前用户能读写。说话记录默认保留 30 天，可以在"设置 › 隐私与数据"里改成 7 天、90 天、一年或一直保留，也可以关掉保存：关掉后只在这次打开期间放在内存里，退出 Tidytalk 就清空。实时字幕只放在内存里，退出就清空。

会议、转写和说话记录可以在资料库里逐条删除，说话记录也可以在"设置 › 隐私与数据"里一次清空；想全部删掉，按使用指南的"卸载"一节操作。

官网

tidytalk.zayen.dev 托管在 GitHub Pages 上，不设置 Cookie。访问量用 Cloudflare Web Analytics 统计：它不用 Cookie，也不追踪个人，只记录汇总的数据，例如看了哪些页面、从哪个网站点过来、浏览器和国家或地区。GitHub 和 Cloudflare 会按各自的隐私政策（GitHub、Cloudflare）处理访问日志（例如 IP 地址）。下载安装包、检查更新也都经过 GitHub。
