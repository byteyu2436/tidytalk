Tidytalk 每个版本的新功能、修复和下载。

0.2.1 最新

2026-10-22 · 下载

  • 转写文件和链接时，每一段开头的字不再被吞掉（录音一开始就有人说话时最明显）。
  • 识别模型说明更准确：Qwen3-ASR 支持 30 种语言和 22 种中文方言（如四川话、东北话、吴语、闽南语）。
  • 识别模型设置页加高了一点，英文界面下底部的说明不再被截断。

安装：需要 macOS 26 或更高版本、Apple 芯片的 Mac。安装包没有经过苹果公证，第一次打开请到"系统设置 › 隐私与安全性"点"仍要打开"，或在终端执行 xattr -dr com.apple.quarantine /Applications/Tidytalk.app。

0.2.0

2026-10-19 · 下载

  • 更多识别模型：在"设置 › 识别模型"里可以换成 Qwen3-ASR（最准，能直接认出词库里的人名和术语）、Fun-ASR-Nano、Whisper Turbo，或 macOS 自带的识别。默认仍是 SenseVoice，所有模型都在本机运行。
  • Apple 智能：支持的 Mac 上可以在"配置 AI"里选 Apple 智能整理和翻译，不需要 API Key，文字不出电脑。
  • 转写文件和链接：菜单里选"转写文件或链接…"，拖入音频、视频文件或粘贴 YouTube、B 站链接，得到带时间的文字，可导出 TXT、SRT 字幕或 Markdown。
  • 自动学词：粘贴后手动改过的词，会提示你一键加入词库，确认后才加入。
  • 实时字幕边听边翻译：不用等一句话说完，译文跟着原文出来。从某一句粘贴改为悬停后点"粘贴"按钮，点句子或拖动字幕条不会误粘贴。
  • 界面整理：菜单栏菜单按用途分组，设置合并为 6 页。

安装：需要 macOS 26 或更高版本、Apple 芯片的 Mac。安装包没有经过苹果公证，第一次打开请到"系统设置 › 隐私与安全性"点"仍要打开"，或在终端执行 xattr -dr com.apple.quarantine /Applications/Tidytalk.app。

0.1.3

2026-10-16 · 下载

  • 新增实时字幕：按 ⌃⌥C 收听电脑播放的声音（视频、网课、会议），在屏幕底部显示字幕，声音同样只在本机识别。可以只听某个应用，字幕条能拖动，样式可选深色或玻璃，没有声音 10 秒后自动隐藏。
  • 字幕翻译：每句说完就用"配置 AI"里的服务翻译，译文显示在原文下面。选 Ollama 或 LM Studio 时全程不联网。
  • 粘贴刚才那段：收听时按 ⌃⌥V，把最近一段话整理后粘贴到光标处；也可以点字幕条上的某一句，从那句粘贴到最新。
  • 第一次打开实时字幕时，macOS 会询问是否允许录制系统音频。

安装：需要 macOS 26 或更高版本、Apple 芯片的 Mac。安装包没有经过苹果公证，第一次打开请到"系统设置 › 隐私与安全性"点"仍要打开"，或在终端执行 xattr -dr com.apple.quarantine /Applications/Tidytalk.app。
