在 Mac 上把录音和视频变成文字

会议录音、网课、采访和视频，转成带时间的文字，可以直接拷贝或导出。声音在本机识别，不会上传。

更新于 2026-10-19

转写一个文件

  1. 点菜单栏里的 Tidytalk 图标，选"转写文件或链接…"。
  2. 把音频或视频文件拖进窗口，或点"选择文件…"。支持 MP3、M4A、WAV、MP4、MOV 等常见格式，最长 3 小时。
  3. Tidytalk 会按停顿把录音切成一句句，逐句识别，每句前面标出时间。
  4. 点"拷贝全文"，或点"导出"保存成纯文本、SRT 字幕或 Markdown。

转写视频链接

粘贴 YouTube、B 站等网站上单个视频的链接，点"转写"。第一次转写链接时，Tidytalk 会从 yt-dlp 的官方 GitHub 下载这个开源下载工具（约 35 MB），并按发布页公布的校验值核对。之后每次只下载视频里的音频，转写完立刻删除。

请只转写你有权使用的内容。需要登录才能看的视频、播放列表和直播暂不支持。

选哪个识别模型

转写文件使用"设置 › 识别模型"里选的模型，所有模型都在本机运行。

模型适合
SenseVoice（默认）速度快，中文、英文、日文、韩文、粤语，中英文混说也没问题。
Qwen3-ASR最准确、标点最好，支持 30 种语言和 22 种中文方言，还能认出词库里的人名和术语。
Whisper Turbo小语种，支持约 99 种语言。中文请用其他模型。

导出格式

  • 纯文本（.txt）：按较长的停顿分段，适合整理笔记，或者交给 AI 总结。
  • 字幕（.srt）：每句一条，带开始和结束时间，可以导入剪辑软件和播放器。
  • Markdown（.md）：标题加上每句的时间和文字，适合放进文档和知识库。

小提示和限制

  • 声音清楚、一次一个人说话时效果最好；背景音乐和多人同时说话会降低准确率。
  • 不会标出是谁在说话。
  • 和说话输入一样，转写结果会套用你的固定替换和中英文排版。
  • 正在进行的会议，用实时字幕更合适：按 ⌃⌥C，电脑播放的声音边播边出字幕。

隐私

识别在本机完成，录音不会上传。转写结果只留在窗口里，拷贝或导出前不会保存到别处。转写链接时，联网的只有第一次下载 yt-dlp 和下载视频的音频。
